# Хоббипедия

Энциклопедия хобби, которая помогает не только прочитать о хобби, но и **выбрать** своё. У каждого хобби одинаковый «паспорт»: затраты на старт и в месяц, время, место, формат, активность и сложность. Поэтому хобби можно сравнивать и фильтровать.

Подробное описание продукта: [PRD.md](PRD.md).

## Как открыть сайт

Дважды щёлкните `index.html`. Сайт сделан на чистых HTML, CSS и немного JavaScript, поэтому устанавливать и собирать ничего не нужно.

## Что внутри

```
index.html          главная: поиск, быстрые подборки, категории
catalog.html        каталог с фильтрами и поиском; ?category=… — страница категории
categories.html     все категории и хобби в них
about.html          о проекте и пороги уровней расходов
hobbies/            страницы хобби (по одному файлу на хобби)
hobbies/_shablon.html  пустой шаблон для новой страницы
css/style.css       все стили (в том числе мобильная версия и тёмная тема)
js/data.js          данные каталога: единственный источник для фильтров и поиска
js/app.js           фильтры, поиск, карточки, проверка данных
```

Страницы хобби работают без JavaScript. JavaScript нужен только каталогу, категориям и главной.

## Как добавить новое хобби

1. Скопируйте `hobbies/_shablon.html` в `hobbies/<slug>.html`, где `slug` — название латиницей через дефис (например, `tennis.html`).
2. Заполните всё в квадратных скобках `[ ... ]`. Удалите необязательные разделы, о которых нечего сказать, и уберите их из оглавления. Пример готовой страницы: `hobbies/vyazanie.html`.
3. Добавьте хобби в массив `hobbies` в `js/data.js` (скопируйте любой блок и поправьте).
4. Откройте `catalog.html`, нажмите F12 и посмотрите вкладку «Консоль». Если в данных есть ошибка, там будет предупреждение «Хоббипедия: найдены ошибки». Например: недопустимое значение, сумма не совпадает с уровнем, «похожее хобби» не существует.

Значения паспорта на странице и в `js/data.js` должны совпадать. Список допустимых значений есть в начале шаблона и в комментарии в `js/data.js`.

## Как поменять суммы и пороги

- **Суммы конкретного хобби** меняются в `js/data.js` (поля `cost_start_kzt` и `cost_monthly_kzt`) и в паспорте и разделе «Затраты» на странице хобби.
- **Пороги уровней** (низкий, средний, высокий) хранятся в `js/data.js` в двух местах: `costStartRange` и `costMonthlyRange` (текст) и `costLimits` (числа для проверки). Их также нужно поправить в таблице на `about.html` и в комментарии шаблона.

## Публикация

Это статический сайт, поэтому его можно бесплатно разместить на любом хостинге статических файлов: GitHub Pages, Netlify, Cloudflare Pages. Публикуется вся папка проекта как есть.

## Что важно проверить

Суммы в тенге — это ориентировочные оценки на октябрь 2026 года. Перед публикацией для широкой аудитории сверьте их с актуальными ценами. По PRD факты нужно проверять.
